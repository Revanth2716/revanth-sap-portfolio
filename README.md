### 2. ⚡ Deep-Tech SAP BASIS Sandboxes
* **Live TMS Transport Lifecycle & Return Code Simulator**: Step through transport `NPLK900142` from DEV workbench object capture (`SE09/SE10`), `tp export` cofile generation, STMS queue inspection, return code evaluation (`RC=0`, `RC=4`, `RC=8`, `RC=12`), and automated CAB release checklist generation.
* **Segregation of Duties (SoD) & Composite Role Hierarchy Matrix**: Live recursion through `AGR_USERS` and `AGR_DEFINE` expanding composite role `Z_FI_FINANCE_MGR` to catch toxic transaction pairs (`FB60` Vendor Invoice vs `F-53` Post Payment) with remediation runbooks.
* **ST12 / ST03 SQL Trace Analyzer & N+1 Query Optimization Lab**: Analyzes raw ST12 traces where 1,840 executions in loops account for 86% of runtime. 1-click optimization to `FOR ALL ENTRIES IN` demonstrates an instant **11.7x performance gain** (4,820 ms down to 410 ms).
* **SAP Interface Cockpit & Message Replay Simulator**: Collapses walls of raw interface logs into single actionable causes with SLA radar and idempotent message replay for RFC, IDoc (`ORDERS05`), and BAPI.
* **HANA Backup RPO & DR Readiness Radar**: Interactive sliders for transaction volume, backup age, and restore test evidence calculating RPO compliance and disk runway before thresholds alert.
* **Interactive 3-Tier Enterprise Architecture Whiteboard**: Deep-dive into Presentation Tier (GUI/Fiori), Application Tier (NetWeaver AS ABAP/Java), and Database Tier (HANA 2.0 & CTS).
* **Landscape Health & 90-Day SLA Uptime**: Real-time status for DEV (`NPL`), QAS (`NPQ`), PRD (`NPP`), SOL, and BW.

## 🚀 Getting Started

### Prerequisites
* Node.js 18.18+ or 20+
* npm

### Installation & Run

```bash
# Navigate to directory
cd "D:\Revanth projects\sap-portfolio"

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
